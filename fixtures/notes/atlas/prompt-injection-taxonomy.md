# Prompt injection in ATLAS (synthetic)

AML.T9901 is Synthetic Prompt Injection, under the tactic Synthetic Initial Access.
AML.T9901.001 is Synthetic Indirect Prompt Injection.
AML.T9999 covers synthetic data theft.
OWASP lists prompt injection as LLM01:2025.
Indirect injections hide instructions in content the model reads later.
