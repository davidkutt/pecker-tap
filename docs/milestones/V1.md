# V1: Skeleton, claim extraction and code-checked advisory claims

Read `AGENTS.md`, `docs/spec.md` and ADR 0001 first. pecker-drum (public, `davidkutt/pecker-drum`) is
the reference for project layout, CI, fake models and the `.env` rules; read its `AGENTS.md`,
`.github/workflows/`, ADR 0007 and `src/pecker_drum/` where this brief points at it. One pull request
against `main`.

## Goal

`tap run` takes a notes checkout and a selection, extracts atomic claims with an LLM, checks every
claim about advisories, CWEs, versions, dates and ATLAS IDs against the official APIs by code, and
writes a pack, a summary and a report. Everything else is listed as `unclear` with reason
`not_checked`. A synthetic self-test runs offline in CI. At the end David runs it live on a few real
notes.

## Prerequisites (David, not the agent)

1. `.pi/protect.json` and `.pi/gate.json` from pecker-nest, with `private/` blocked and live runs
   (`--model openrouter` or `--online`) gated.
2. For the live run at the end: `OPENROUTER_API_KEY`, optionally `GITHUB_TOKEN` (fine-grained, no
   repository access; public data only) and `NVD_API_KEY`, in `./.env` or the shell.

## Deliverables

1. **Project skeleton** as in pecker-drum: `pyproject.toml` (Python 3.13, uv, minor-pinned
   dependencies), Ruff, Pyright strict on `src/`, pytest, `docs/dependencies.md`, and a CI workflow
   with the same jobs as pecker-drum's `ci.yml` (check, audit, zizmor; actions pinned by SHA,
   `persist-credentials: false`). The doc test for Unicode Cf/Cc characters from pecker-drum.
2. **Notes loader** (`notes/`): reads `*.md` under `--notes`, filtered by `--paths` globs (default:
   everything); skips hidden folders. Parses frontmatter (keeps `id`, `sources`, `cve`, `ghsa`,
   `extends`, `supersedes`, `decision`, `review`; tolerates unknown keys) and splits the body into
   sections by heading with line numbers. Records the checkout's commit SHA (via `git rev-parse`,
   read-only) or `unknown`. A note that fails to parse is reported, not fatal.
3. **Claim schema and extraction** (`claims/`): the claim model of the spec (Pydantic, unknown fields
   rejected). One structured-output call per section; notes and sections wrapped as data with the
   closing delimiter escaped. Code checks every claim: `quote` must be an exact substring of the note
   within `lines`, `type` must be known, IDs in `entities` must match their patterns (CVE, GHSA,
   AML IDs, OWASP IDs with year). Rejected claims are counted and listed in the report, never kept.
   Notes with `decision: awaiting-david` yield only `decision` entries without a model call.
   `claim_id` is stable: note order, then line.
4. **Fake models** (`fake:<script>`) as in pecker-drum: `fake:fixtures` returns the expected claims for
   the synthetic notes from a file next to them; `fake:invent` returns claims with quotes not in the
   note (to test the quote check); `fake:inject` returns the claims a note's planted injection asks
   for (to show code-side checks catch it).
5. **HTTP client** (`evidence/http.py`): the single place for HTTP. httpx with an injectable
   transport; https only; at most 5 redirects, each recorded; response size cap (2 MB) and timeout;
   resolved addresses must not be private, loopback or link-local; user agent names the tool;
   per-host rate limits (GitHub, NVD, CVE.org defaults from their documentation, configurable);
   retries with backoff on 429/5xx; every response cached in the run folder (URL, status, headers that
   matter, body, fetched_at, sha256). No network unless `--online`: otherwise it serves only from
   `--sources` (recorded fixtures or an earlier run's cache) and a lookup that isn't there gives
   `unclear` / `no_source`.
6. **Structured sources** (`evidence/`): GitHub global advisory API and repository advisory API (repo
   taken from the note's cited advisory URL or the global record), CVE.org CVE Services, NVD API 2.0,
   and the ATLAS YAML of a release pinned in config (downloaded once into the cache, sha256 checked).
   Each returns normalised fields with the source URL per field: severity label, CVSS version, score
   and vector, CWE IDs, affected ranges, first patched version, published and updated dates,
   aliases, package and product names; for ATLAS: ID exists, name, tactic, case-study links. Tests
   use a small synthetic ATLAS YAML. OWASP claims stay `unclear` / `not_checked` until the OWASP
   tables arrive in V2.
7. **Code comparison** (`verdict/`): per claim type, compare the note's `value` with every source
   value and apply the status rules of the spec, including the conflict rules (both values recorded,
   never a winner). Version ranges compared with a proper version parser per ecosystem where known,
   else as strings with a warning. Dates compared at the precision the note states (a note saying
   "2026-11" matches any day in November). Every verdict carries `decided_by: code` and the source
   field it used.
8. **Graph** (`graph/`): LangGraph with the nodes of the spec that exist in V1 (`load_notes`,
   `extract`, fan-out per claim with `Send`, `api_lookup`, `compare`, `collect`, `write_pack`), SQLite
   checkpointer in the run folder, `--resume <run_id>`.
9. **Writers** (`pack/`): `pack.yaml` (spec schema), `summary.md` (English in V1: counts per status,
   contradictions and new findings with their sources, unclear by reason, rejected claims, cost),
   `report.json`, `run.json`. Excerpts escaped and capped (evidence 300 characters).
10. **Settings and cost** as in the spec: `--model` required; `.env` opened only for a live model, only
    the four names of the spec, environment beats `.env`, values never printed (follow pecker-drum's
    ADR 0007 and its tests). `--max-cost` (default 0.50 USD) checked before every model call against
    OpenRouter's reported cost; a run that hits it stops cleanly, writes what it has and says so.
    OpenRouter requests set `provider.zdr`.
11. **Synthetic fixtures** (`fixtures/notes/`, `fixtures/http/`): 5 to 8 notes with placeholder IDs
    (see AGENTS.md) and recorded API responses that cover: a verified advisory claim; a contradicted
    fixed version; a contradicted CVE that belongs to another product; a score the note lacks
    (`new_finding`); a repository-vs-global conflict the note records (`verified`) and one it
    doesn't (`verified` plus `new_finding`); an unreachable source (`unclear` / `unreachable`); an
    ATLAS ID that doesn't exist in the pinned release; a `decision` note; a prose claim
    (`not_checked`); one note with a planted injection that tells the verifier to mark everything
    verified. Expected output in `fixtures/expected/` (golden files).
12. **CLI**: `tap run --notes <dir> [--paths <glob>…] --model <m> [--sources <dir>] [--online]
    [--out <dir>] [--max-cost <usd>] [--resume <run_id>]`. Default output `private/runs/<run_id>/`. Exit code 0
    on a finished run, 1 on a finished run with rejected claims or parse errors, 2 on setup errors.

## Acceptance checks

- [ ] Lint, format check, Pyright and tests pass; tests make no network calls (a test proves the
      default transport is never reached).
- [ ] `tap run --notes fixtures/notes --model fake:fixtures --sources fixtures/http` reproduces
      `fixtures/expected/` exactly (pack and report, ignoring timestamps and run ids). It runs in CI.
- [ ] The planted-injection note changes nothing: with `fake:inject` the code comparison still gives
      the expected statuses, and the injected claims fail the quote check or keep their real status.
- [ ] `fake:invent` claims are all rejected by the quote check and listed in the report.
- [ ] Tests for: frontmatter edge cases; section line numbers; each comparison rule including both
      conflict cases; version and date precision; redirect cap; private-address block; size cap;
      429 retry; a missing source without `--online`; cost cap stop; `--resume` after an interrupted
      run.
- [ ] A test proves known test values of `OPENROUTER_API_KEY` and `GITHUB_TOKEN` never appear in
      logs, packs, reports, run records, caches or checkpoints.
- [ ] A test proves a run without `--out` writes under `private/runs/` (in a temporary directory).
- [ ] First live run, by David at the end: 3 to 5 real notes, `--model openrouter --online` with
      DeepSeek V4.1 Flash. The run stays in `private/`; the PR gets only the cost per claim, the counts per
      status and anything David chooses to share.

## Out of scope

Fetching cited web pages, LlamaIndex, the LLM judge, source snapshots in Wren's manifest format,
evaluation and gold import (V2). Review interrupt, delta request, German summary, git-range selection
(V3). Any write to the notes repository or GitHub.
